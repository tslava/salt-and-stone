# Соль и камень

[English](README.md)

Небольшая браузерная игра о восхождении по двум песчаниковым скалам над морем. Основной экран — телефон, вертикальная ориентация. Маршрут спроектирован вручную; генератора уровней нет.

Отложенные изменения и идеи: [планы развития](docs/ROADMAP.md).

## Запуск и плейтест

Онлайн: **https://tslava.github.io/salt-and-stone/**

Локально:

```sh
npm run dev
```

Сервер напечатает адрес для этого компьютера и для телефона в той же сети.

Для игры достаточно Node.js 22+, установка зависимостей нужна только для проверок. В браузере нет внешних зависимостей, шрифтов, фотографий или запросов к сторонним сервисам.

## Управление

1. Коснитесь зацепа в светлом кольце. Все геометрически доступные следующие опоры отмечены заранее; вокруг каждого маркера область нажатия 48×48 CSS px.
2. Выбранное кольцо увеличится, появится траектория. Камера во время выбора неподвижна. Касание само по себе не двигает героя.
3. Нажмите постоянную кнопку внизу: «Перехват», «Прыжок» или «Отход». Там же показан расход сил либо использование резерва.
4. Прыжок готовится автоматически после подтверждения. До начала движения его можно отменить кнопкой «Отменить прыжок».
5. Для смены цели коснитесь другого кольца. Для отмены нажмите «Снять выбор». Нижние опоры выбираются точно так же.

Тип движения определяется расстоянием до опоры. Все маркеры одинаковой круглой формы; ромбов, направленных свайпов и удержания для выбора в интерфейсе больше нет. Если сил недостаточно, цель можно осмотреть, но кнопка движения недоступна.

На широком уступе с растительностью силы восстанавливаются автоматически, в том числе во время выбора цели. Он же становится точкой повторной попытки. Висение начинает расходовать силы после четырёх секунд. Прыжки требуют больше сил, чем перехваты; случайных срывов нет.

Для отхода по уже пройденным опорам есть отдельный резерв. Выберите предыдущую опору и подтвердите отход даже при пустой основной шкале. Обратные прыжки также используют резерв и автоматическую подготовку. Резерв не оплачивает продвижение вперёд.

Пауза находится справа вверху. Из неё можно вернуться на последний уступ и включить короткие звуковые сигналы. При потере фокуса игра встаёт на паузу, выбор и подготовка прыжка отменяются. Поворот экрана также снимает выбор. Во время движения ввод не накапливается. Прогресс хранится только в текущей вкладке.

## Маршрут

Первая скала учит боковому перехвату и прыжку через рассечение. Затем можно продолжить напрямую либо отклониться к Сосновому балкону. Прыжок через пролив ведёт к Ветряной игле: здесь меняется направление подъёма, встречается нависающий скол и появляется ещё один обход к отдыху. Завершение — отдельное движение выхода на вершину и торжественное поднятие обеих рук.

Осмысленный осторожный путь: 26 движений, 7 прыжков. Прямой: 21 движение, 7 прыжков. Оба проверены без падений. Подробные результаты и границы проверки: [docs/PLAYTEST.md](docs/PLAYTEST.md).

## Проверки и сборка

```sh
npm ci --cache .npm-cache
npm run check
npm test
npm run build
npm run test:browser
```

`check` проверяет синтаксис модулей и форматирование. `test` запускает 26 тестов механики, маршрута, анимации и нового выбора касанием. `build` создаёт самостоятельную папку `dist/`. Её можно обслуживать командой `node scripts/server.mjs --dist` после остановки другого экземпляра сервера.

Актуальный браузерный тест — `scripts/tap-browser-test.mjs`; он проверяет выбор касанием и подтверждение, весь маршрут и маленький экран. Ранние сценарии проверки свайпов сохранены как исторические и не входят в `test:browser`.

Браузерные проверки используют локальный Google Chrome и Playwright. На другой системе задайте `CHROME_PATH` путём к исполняемому файлу Chrome. Для записи MP4 требуется `ffmpeg`; на обычную игру эти инструменты не влияют.

Проверка материала и силуэта:

- http://localhost:5187/?art=clay
- http://localhost:5187/?art=silhouette

`?debug=1` открывает инструменты инспекции только в этой вкладке. Тестовые фикстуры не включаются в обычный игровой интерфейс.

## Устройство проекта

- `src/route.js` — ручные зацепы, выбор цели, стоимость движения и проверка препятствий всем телом.
- `src/engine.js` — ввод, состояния, выносливость, отдых, падение и завершение.
- `src/rig.js` — фиксированные длины костей, кисти и стопы, перехват, прыжок и выход на вершину.
- `src/art.js` — контуры массивов, крупные грани, рельеф пластов и трещины.
- `src/render.js` — Canvas 2D, море, атмосфера, скалы, герой и предпросмотр.
- `src/main.js`, `src/style.css` — интерфейс, касания, пауза и звук.
- `artifacts/` — исследовательский референс, кадры, записи движения и отчёты проверок. В сборку не входят.

Художественное исследование и источники: [docs/ART-DIRECTION.md](docs/ART-DIRECTION.md).

Игра опубликована на GitHub Pages; платные сервисы не используются.
